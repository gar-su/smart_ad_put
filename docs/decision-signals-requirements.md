# 决策信号与决策日志需求
## 一、背景与范围
信号体系从 v1.0 的单一 `FOLLOW_UP` 扩展为 `FOLLOW_UP` + `ELIMINATE` 双向信号。
素材维度选品目前处于策略验证与原型展示阶段：已完成生命周期规则、A 方案三道选品闸门和离线回测，用于验证选品规则与前端展示形态。
本期范围：
- 产品：新增 `ELIMINATE` 淘汰信号；新增素材信号口径

## 二、信号体系总览
| 信号 | 业务语义 | 目标维度 | 下游动作 |
|---|---|---|---|
| `FOLLOW_UP` | 目标值得继续投放 | product / campaign / material | 新建放量任务 |
| `ELIMINATE` | 目标已不值得投放 | product | 停止投放并移除任务 |
两类信号共用 `BuildSignal` 字段契约，字段结构完全一致，仅 `signal_type` 不同。
冷却键为 `(目标, 信号类型)`，`FOLLOW_UP` 与 `ELIMINATE` 各自独立冷却，互不抑制。
下游按 `(target_dimension, target_id, signal_type)` 幂等；`signal_id` 含生成时间戳，仅用于追踪，不作为下游幂等键。

## 三、ELIMINATE 淘汰信号
### 3.1 目标与非目标
**目标**：
- 新增 `ELIMINATE`，覆盖短剧维度的退出期与衰退期
- 信号到达下游后，停止该短剧的自动化投放并移除任务
- 淘汰后若 ROI 回升，允许重新跟投入池
**非目标**：
- Campaign / 素材维度的淘汰本期不做
- 本系统不执行停投、删任务等动作，只输出信号
- 不做本地去重，由下游按目标维度幂等处理
### 3.2 触发口径
触发阶段取现有短剧生命周期判定结果，不新增判定规则：
| 阶段 | 置信度 |
|---|---|
| `product_exit` | 0.85 |
| `product_decline` | 0.80 |
两个阶段纳入可配置的淘汰阶段范围，可调整；与跟投阶段不得有交集。
### 3.3 重入策略
允许重入跟投名单，淘汰不写持久化黑名单：
- 淘汰后若阶段回升到 `product_entry` / `product_growth` / `product_sustained`，`FOLLOW_UP` 照常产出，下游重新建任务
- `FOLLOW_UP` 与 `ELIMINATE` 各自独立冷却，冷却键为（目标，信号类型），互不抑制
- 下游按目标最后一条信号理解当前状态：先 `ELIMINATE` 后 `FOLLOW_UP` 表示重新入池
### 3.4 幂等与去重
本系统不做跨进程去重，重复运行 pipeline 可能重复产出同一信号。下游按 `(target_dimension, target_id, signal_type)` 幂等：
- 已在池内的目标重复收到 `ELIMINATE` 时不重复执行移除
- 池外目标收到 `ELIMINATE` 时按空操作处理
### 3.5 不要求先有跟投
`ELIMINATE` 按阶段无条件产出，不检查目标是否曾收到 `FOLLOW_UP`、是否在自动化池内。
原因：系统不维护投放状态；若以「曾跟投」为前提，需额外持久化状态；且短剧停投后数据源不可见。
### 3.6 字段契约
复用 `BuildSignal`，仅 `signal_type` 新增枚举值：
| 字段 | 淘汰信号取值 |
|---|---|
| `signal_id` | `YYYYMMDDHHMMSS_目标ID`，含生成时间戳，仅用于追踪 |
| `signal_type` | `ELIMINATE` |
| `target_dimension` | `product` |
| `target_id` | 短剧视频 ID |
| `language_code` | 透传 |
| `script_no` | 透传剧本编号 |
| `shortplay_name` | 透传短剧名 |
| `reason` | 生命周期判定理由 |
| `confidence` | 阶段判定置信度，非淘汰概率 |
| `timestamp` | 信号生成时间（UTC） |
### 3.7 配置
信号配置需要支持：
| 配置项 | 默认值 | 说明 |
|---|---|---|
| 淘汰阶段 | product_exit / product_decline | 产出 `ELIMINATE` 的阶段，可调整 |
跟投阶段与淘汰阶段不得重叠；重叠时配置不生效并提示。

## 四、素材维度 FOLLOW_UP
### 4.1 现状
素材选品：已完成生命周期规则、A 方案三道选品闸门和离线回测。
### 4.2 选品口径
- 阶段为 `material_entry` 或 `material_sustained`
- 且通过 A 方案三道闸门：累计 ROI > 50%、ROI 波动率 <= 0.50、日均消耗 >= 200
- 三关全过才产 `FOLLOW_UP(material)`
#### 4.2.1 数据需求
| 类别 | 字段 | 要求 |
|---|---|---|
| 主体 | material_id | 稳定唯一，素材 filename |
| 时间 | date | 素材 × 自然日，每天一行 |
| 归属 | language_code / script_no / shortplay_name | 信号分流与展示必需 |
| 消耗 | spend | number ≥ 0，当日消耗 |
| 收入 | income_order / income_ad | number ≥ 0，订单充值 / IAA 分成 |
| 流量 | impressions / clicks | number ≥ 0，用于 CTR 与疲劳判定 |
| 可选 | active_cnt、所属短剧 ID | 诊断辅助 |

- 覆盖：当日有消耗的全部素材，非 TopN；每个素材提供从首投到昨日的完整历史，零消耗日显式 0
- 最少历史：首判 2 个活跃日；持续判定 5 个活跃日；建议保留 14 天
- 质量：数值型、无 null、币种 / 时区统一；不供 ROI / CTR 等派生指标；日更，凌晨 2 点前到达
- 量级：约 1.4 万素材，日增约 3 千条有消耗记录
- 派生指标：ROI、活跃日、近 2/3/5 日 ROI、ROI 波动率、日均消耗、CTR 均由本系统计算，公式见附录 A.4
#### 4.2.2 首判时点
素材在第 2 个活跃日开始判定；第 1 个活跃日只观察。留出集单票判定对比：

| 首判时点 | 入选数 | 覆盖率 | 精确率 |
|---|---|---|---|
| 第 1 个活跃日 | 28 | 1.1% | 57.1% |
| 第 2 个活跃日 | 51 | 2.9% | 78.4% |
| 第 3 个活跃日 | 39 | 3.5% | 74.4% |

第 1 天样本少、波动大，不采用；第 2 天相比第 3 天提前 1 天且精确率不降。第 2 天早期 / 后期窗口精确率 86.7% / 75.0%。留出集样本量较小（51 / 39），上线前需扩大样本复核。
上表是各时点的单票 cohort；第 2 天未通过的素材仍可在后续活跃日再次判定。
#### 4.2.3 判定逻辑
活跃日 = 当日消耗 > 0 的自然日。

| 活跃日 | 条件 | 阶段 | 是否进入选品 |
|---|---|---|---|
| < 2 | 时间不足 | `material_observing` | 否 |
| 2-4 | 累计 ROI < 10% | `material_eliminated` | 否 |
| 2-4 | 累计 ROI > 40% 且近 2 日消耗占比 >= 50% | `material_entry` | 是 |
| 2-4 | 其他 | `material_observing` | 否 |
| >= 5 | 近 3 日 ROI < 10% | `material_eliminated` | 否 |
| >= 5 | 近 3 日 ROI > 40% 且近 2 日 ROI 均值 >= 30% 且近 2 日消耗占比 >= 50% | `material_sustained` | 是 |
| >= 5 | 10% <= 近 3 日 ROI <= 40% 且曾达标且（近 2 日 ROI 较峰值降 > 50% 或近 2 日 CTR 较前 3 日降 > 20%） | `material_fatigue` | 否 |
| >= 5 | 其他 | `material_observing` | 否 |
曾达标 = 全部活跃日的单日 ROI 峰值 ≥ 40%，即峰值日 ROI ≥ 0.40；峰值日 ROI = 全部活跃日 `max(单日 ROI)`，不按消耗加权，小消耗日可能把峰值顶高。疲劳期仅在近 3 日 ROI 10%-40% 区间判定，低于 10% 判淘汰、高于 40% 判稳定，三阶段按 ROI 区间互斥，不依赖判断顺序。ROI 疲劳比较的是近 2 日 ROI 算术均值与单日峰值，两者口径不同。
#### 4.2.4 产出逻辑
只有 `material_entry` / `material_sustained` 进入选品，按顺序通过三道闸门：

| 顺序 | 闸门 | 阈值 | 含义 |
|---|---|---|---|
| 1 | 累计 ROI | > 50% | 盈利线之上的选品余量 |
| 2 | ROI 波动率 | <= 0.50 | 过滤一日冲高 |
| 3 | 日均消耗 | >= 200 | 已被放量验证 |

三关全过才产 `FOLLOW_UP(material)`，字段见 4.3。
- 冷却：默认 24 小时，按 `(material_id, FOLLOW_UP)` 计
- 幂等：下游按 `(target_dimension, target_id, signal_type)` 去重
- 重入：阶段回升到入场期 / 稳定期且闸门再次通过，冷却期后可重新产出
- 信号不带 scale，放量规模由下游模板承载
### 4.3 展示字段
沿用 `BuildSignal` 标准字段，不新增闸门指标字段：
| 字段 | 素材取值 |
|---|---|
| `signal_type` | `FOLLOW_UP` |
| `target_dimension` | `material` |
| `target_id` | 素材 filename |
| `language_code` | 素材语言 |
| `script_no` | 剧本编号 |
| `shortplay_name` | 所属短剧名 |
| `reason` | 选品通过原因，文本内可带闸门数值 |
| `confidence` | 生命周期阶段判定置信度 |
| `timestamp` | 信号生成时间 |
### 4.4 mock 数据
决策日志新增 4 条素材 mock 信号，覆盖英语 / 韩语 / 阿拉伯语 / 西班牙语，`reason` 形如：
`选品通过: 累计ROI=68.4% > 50%，波动率=0.23 ≤ 0.50，日均消耗=412.0 ≥ 200`

## 附录 A：指标定义与计算公式
本附录定义判定与选品用到的全部派生指标，公式与判定服务实现一致。`R_i` 表示第 i 个统计日的收入，`C_i` 表示对应消耗，`r_i = R_i / C_i` 表示单日 ROI；统计日按日期升序排列，`n` 为统计日总数。
### A.1 通用口径
| 指标 | 公式 | 说明 |
|---|---|---|
| 收入 | `R_i = incomeOrder_i + incomeAd_i` | 订单充值 + IAA 广告分成 |
| 单日 ROI | `r_i = R_i / C_i`，`C_i = 0` 时记 0 | 单日投资回报率 |
| 累计 ROI | `ΣR_i / ΣC_i`，`ΣC_i = 0` 时记 0 | 消耗加权；不是日 ROI 的算术平均 |
| 观测跨度 | `(末条日期 - 首条日期).days + 1` | 短剧按自然日，广告单元按小时 |
| 近 N 日 | 按日期升序取最近 N 个统计日的尾部窗口 | 统计日口径随维度不同，见 A.2 ~ A.4 |
### A.2 短剧维度
| 指标 | 公式 | 使用位置 |
|---|---|---|
| 日 ROI 序列 | 按自然日升序每天一条；`C_i = 0` 的日保留并记 `r_i = 0` | 全部短剧判定 |
| 投放天数 | `duration_hours / 24` | 阶段分段 |
| 近 3 天 ROI 均值 | `(r_{n-2} + r_{n-1} + r_n) / 3` | 入场 / 退出 / 稳定 / 趋势 |
| 前 3 天 ROI 均值 | `(r_{n-5} + r_{n-4} + r_{n-3}) / 3` | 趋势上升 |
| 趋势上升 | `近3天均值 > 前3天均值 × 1.2` 且 `近3天均值 > 0.40` | 成长期 |
| 近 5 天 ROI 区间 | `0.30 ≤ r_i ≤ 0.80`，`i = n-4 ~ n` | 稳定期（≥14 天） |
| 持续低 ROI（5 天） | `r_i < 0.10`，`i = n-4 ~ n` | 退出期（≥14 天） |
| 近 3 天低 ROI | `(r_{n-2} + r_{n-1} + r_n) / 3 < 0.10` | 退出期（7-14 天） |
| 前后半段跌幅 | `mid = ⌊n/2⌋`；`(mean(r_1 ~ r_mid) - mean(r_mid+1 ~ r_n)) / mean(r_1 ~ r_mid)`；前半段均值 > 0 且跌幅 > 0.30 判衰退 | 衰退期（7 天以上） |
### A.3 广告单元维度
| 指标 | 公式 | 说明 |
|---|---|---|
| 小时序号 | `date.toordinal() × 24 + hour` | 用于连续性与分段 |
| 观测小时跨度 | `末小时序号 - 首小时序号 + 1` | 小时序列需连续 |
| 分段窗口 | `offset < 24` / `24 ≤ offset < 72` / `offset ≥ 72`，`offset = 当前小时序号 - 首小时序号` | 0-24h / 24-72h / 72h+ |
| 分段 ROI | 窗口内 `ΣR_i / ΣC_i`，`ΣC_i = 0` 时记 0 | 三段分别计算 |
| 累计 ROI | 全部小时 `ΣR_i / ΣC_i`，`ΣC_i = 0` 时记 0 | 全周期 |
| 峰值 ROI | `max(roi_0_24h, roi_24_72h, roi_72plus)` | 分段 ROI 最大值 |
| 较峰值降幅 | `(峰值ROI - 累计ROI) / 峰值ROI` | 峰值 > 0.40 且累计 < 峰值 × 0.5 判衰退 |
| 后期走强 | `roi_72plus > roi_0_24h × 1.5` | 趋势向好 |
| 后期走弱 | `roi_72plus < roi_0_24h × 0.5` 且 `roi_72plus > 0` | 趋势下滑 |
### A.4 素材维度
| 指标 | 公式 | 说明 |
|---|---|---|
| 活跃日 | `C_i > 0` 的自然日数 | 零消耗日不进入任何窗口 |
| 日 ROI 序列 | `r_i = R_i / C_i`，仅活跃日，按日期升序 | — |
| 累计 ROI | 全部活跃日 `ΣR_i / ΣC_i` | 选品闸门 1 |
| 近 3 日 ROI | 最近 3 个活跃日 `ΣR_i / ΣC_i` | 阶段判定；消耗加权 |
| 近 2 日 ROI 均值 | `(r_{n-1} + r_n) / 2`，最近 2 个活跃日 | 阶段判定；算术平均 |
| 近 2 日消耗占比 | 最近 2 个活跃日 `ΣC_i` / 全部活跃日 `ΣC_i` | 消耗萎缩判定 |
| 峰值日 ROI | 全部活跃日 `max(r_i)` | 疲劳判定；单日 ROI 最大值，不按消耗加权 |
| 曾达标 | `峰值日 ROI ≥ 0.40` | 疲劳判定前置条件；ROI / CTR 两分支均适用 |
| 疲劳区间 | `0.10 ≤ 近3日ROI ≤ 0.40` | 与淘汰期、稳定期按区间互斥 |
| ROI 波动率 | `pstdev(r_1 ~ r_n) / mean(r_1 ~ r_n)`；`pstdev = sqrt(Σ(r_i - mean)² / n)`；均值 ≤ 0 时记 0 | 选品闸门 2；总体标准差 |
| 日均消耗 | 全部活跃日 `ΣC_i / n` | 选品闸门 3 |
| 窗口 CTR | 窗口内 `Σclicks_i / Σimpressions_i`；曝光为 0 时记 0 | 疲劳判定 |
| 近 2 日 CTR | 最近 2 个活跃日的窗口 CTR | 疲劳判定 |
| 前 3 日 CTR | 最近 2 个活跃日之前的 3 个活跃日的窗口 CTR | 疲劳判定 |
| ROI 疲劳降幅 | `近2日ROI均值 < 峰值日ROI × (1 - 0.50)` | 疲劳判定；要求曾达标 |
| CTR 疲劳降幅 | `近2日CTR < 前3日CTR × (1 - 0.20)` | 疲劳判定；要求曾达标且前 3 日 CTR > 0 |
### A.5 口径差异提示
- 短剧「近 3 天 ROI 均值」是日 ROI 的算术平均，三天等权；素材「近 3 日 ROI」是窗口 Σ收入 / Σ消耗，消耗加权。两者数值不可直接比较。
- 短剧日序列保留零消耗日并记 ROI = 0；素材只统计活跃日，零消耗日完全剔除。
- 前后半段跌幅按全部历史对半分，不是近 N 日窗口；历史越长，早年高点对当前判定的影响越持久。
- pipeline 原型直接使用平台下发的 `roi` 百分比串，不走本附录的服务内计算；两条链路口径差异见 PRD §6.3 待定决策 1。
- 实现口径待对齐项：素材首判时点本文为第 2 个活跃日、入场条件本文写累计 ROI，当前实现分别为第 3 个活跃日、近 3 日 ROI；活跃日 ≤ 3 时累计 ROI 与近 3 日 ROI 相同，第 4 天起分叉。
- 峰值日 ROI 取全部活跃日单日 ROI 的最大值，不按消耗加权；小消耗日的高比值可把峰值顶高，使后续正常投放更容易触发「较峰值降 > 50%」的疲劳判定。
