# 素材选择策略需求（A 方案）
## 1. 背景与目标
基于 short-drama-scoring 提供的素材日级数据做素材选择，不使用 LightGBM 模型。
生命周期规则树先筛出入场期 / 稳定期素材；在此基础上增加选品闸门，把「ROI 过了 40% 盈利线」收紧为「值得新建投放」。
目标：把首次信号的未来 ROI 达标精确率从 38.4% 提升到 70% 以上，接受覆盖率下降。
## 2. 数据与口径
| 项 | 定义 |
|---|---|
| 数据源 | short-drama-scoring 提供的素材日级数据 |
| 时间范围 | 2026-06-20 ~ 2026-07-09 |
| 素材数 | 14,423 条；有消耗素材 12,342 条 |
| 活跃日 | 当日消耗 > 0 的自然日；零消耗日不进入 ROI 序列 |
| ROI | (订单充值 + IAA 广告分成) / 消耗 |
| 标签 | 观测点之后活跃日的累计 ROI >= 40% |
| 切分 | material_id SHA-256 哈希，70% 校准 / 30% 留出，素材不跨集 |
### 2.1 指标口径与计算公式
`R_i` 表示第 i 个活跃日的收入（订单充值 + IAA 广告分成），`C_i` 表示当日消耗，`r_i = R_i / C_i` 表示单日 ROI；活跃日按日期升序排列，`n` 为活跃日数。
| 指标 | 公式 | 说明 |
|---|---|---|
| 活跃日 | `C_i > 0` 的自然日数 | 零消耗日不进入任何窗口 |
| 单日 ROI | `r_i = R_i / C_i` | 仅活跃日计算 |
| 累计 ROI | 全部活跃日 `ΣR_i / ΣC_i` | 闸门 1 使用 |
| 近 3 日 ROI | 最近 3 个活跃日 `ΣR_i / ΣC_i` | 阶段判定；消耗加权，不是三日 ROI 的算术平均 |
| 近 2 日 ROI 均值 | `(r_{n-1} + r_n) / 2` | 阶段判定；算术平均 |
| 近 2 日消耗占比 | 最近 2 个活跃日 `ΣC_i` / 全部活跃日 `ΣC_i` | 消耗萎缩判定 |
| 峰值日 ROI | 全部活跃日 `max(r_i)` | 疲劳判定；单日 ROI 最大值，不按消耗加权 |
| 曾达标 | `峰值日 ROI >= 40%` | 疲劳判定前置条件；ROI / CTR 两分支均适用 |
| 疲劳区间 | `10% <= 近3日 ROI <= 40%` | 与淘汰期、稳定期按区间互斥 |
| ROI 波动率 | `pstdev(r_1 ~ r_n) / mean(r_1 ~ r_n)`；`pstdev = sqrt(Σ(r_i - mean)² / n)`；均值 ≤ 0 时记 0 | 闸门 2；总体标准差 |
| 日均消耗 | 全部活跃日 `ΣC_i / n` | 闸门 3 |
| 窗口 CTR | 窗口内 `Σclicks_i / Σimpressions_i`；曝光为 0 时记 0 | 疲劳判定 |
| 近 2 日 CTR | 最近 2 个活跃日的窗口 CTR | 疲劳判定 |
| 前 3 日 CTR | 最近 2 个活跃日之前的 3 个活跃日的窗口 CTR | 疲劳判定 |
注：波动率是标准差除以均值，不是百分比区间；`<= 0.50` 表示日 ROI 标准差不超过均值的一半。所有窗口按活跃日取，不是自然日。
当前实现与本文的差异：首判时点为第 3 个活跃日（本文为第 2 个）；入场判定使用近 3 日 ROI（本文 §3 写累计 ROI），活跃日 ≤ 3 时两者相同，第 4 天起分叉。
峰值日 ROI 取单日 ROI 最大值，小消耗日的高比值可把峰值顶高；ROI 疲劳比较的是近 2 日 ROI 算术均值与单日峰值，两者口径不对等。
## 3. 生命周期判定树
| 活跃日 | 条件 | 阶段 | 是否进入选品 |
|---|---|---|---|
| < 2 | 时间不足 | `material_observing` | 否 |
| 2-4 | 累计 ROI < 10% | `material_eliminated` | 否 |
| 2-4 | 累计 ROI > 40% 且近2日消耗占比 >= 50% | `material_entry` | 是 |
| 2-4 | 其他 | `material_observing` | 否 |
| >= 5 | 近3日 ROI < 10% | `material_eliminated` | 否 |
| >= 5 | 近3日 ROI > 40% 且近2日 ROI 均值 >= 30% 且近2日消耗占比 >= 50% | `material_sustained` | 是 |
| >= 5 | 10% <= 近3日 ROI <= 40% 且曾达标且（近2日 ROI 较峰值降 > 50% 或近2日 CTR 较前3日降 > 20%） | `material_fatigue` | 否 |
| >= 5 | 其他 | `material_observing` | 否 |
曾达标 = 峰值日 ROI >= 40%；峰值日 ROI 为全部活跃日单日 ROI 的最大值，不按消耗加权。疲劳期仅在近 3 日 ROI 10%-40% 区间判定，低于 10% 判淘汰、高于 40% 判稳定，三阶段互斥。ROI 疲劳为近 2 日 ROI 算术均值与单日峰值比较。
首判时点：第 2 个活跃日开始判定，第 1 个活跃日只观察。留出集单票对比：

| 首判时点 | 入选数 | 覆盖率 | 精确率 |
|---|---|---|---|
| 第 1 个活跃日 | 28 | 1.1% | 57.1% |
| 第 2 个活跃日 | 51 | 2.9% | 78.4% |
| 第 3 个活跃日 | 39 | 3.5% | 74.4% |

采用第 2 天：相比第 3 天提前 1 天，精确率不降；第 2 天早期 / 后期窗口 86.7% / 75.0%。留出集样本量较小，上线前需扩大样本复核。
上表是各时点的单票 cohort；第 2 天未通过的素材仍可在后续活跃日再次判定。
规则调整记录：旧版 >= 5 天按「淘汰 → 疲劳 → 稳定」顺序判定，Day 5 有 98 个稳定候选被疲劳抢占。现改为按近 3 日 ROI 区间互斥判定（淘汰 <10%、稳定 >40%、疲劳 10%-40%），Day 5 稳定期由 101 条恢复至 199 条、疲劳期由 835 条降至 409 条，稳定期精确率由 45.5% 提升至 48.2%。
## 4. 选品闸门（A 方案）
只有 `material_entry` / `material_sustained` 进入选品，按顺序过三道闸门：
| 顺序 | 闸门 | 阈值 | 含义 |
|---|---|---|---|
| 1 | 累计 ROI | > 50% | 40% 只是盈利线，50% 以上才有选品余量 |
| 2 | ROI 波动率 | <= 0.50 | 过滤一天冲高、后续回落的素材 |
| 3 | 日均消耗 | >= 200 | 系统已经用钱投票，消耗规模是被验证的显性信号 |
三关全过才产 `FOLLOW_UP(material)` 信号。
## 5. 回测结果（Day 3 基线）
产品口径已提前到 Day 2；下表是 Day 3 基线，用于和 Day 2 对比。
| 口径 | 信号数 | 覆盖率 | 精确率 | 相对基线 |
|---|---|---|---|---|
| 全集 · 原始阶段信号 | 1,283 | 33.6% | 37.3% | 1.77x |
| 全集 · A 方案闸门后 | 111 | 2.9% | 73.0% | 3.46x |
| 留出集 · 原始阶段信号 | 366 | 33.2% | 38.8% | 1.83x |
| 留出集 · A 方案闸门后 | 37 | 3.4% | 73.0% | 3.44x |
| 校准集 · A 方案闸门后 | 74 | 2.7% | 73.0% | 3.47x |
闸门逐级淘汰：原始 1,283 → ROI 达标 781（淘汰 502）→ 波动达标 215（淘汰 566）→ 消耗达标 111（淘汰 104）。
时间稳定性：早期窗口（首投 06-20 ~ 06-29）精确率 78.0%，后期窗口（06-30 ~ 07-09）70.0%。
口径敏感性：A 方案闸门后，充值口径全集 50 条 / 32.0%，留出集 16 条 / 37.5%，明显低于合并口径。

## 8. 范围与边界
- 本期只做策略验证与原型展示，不涉及正式投放信号下发；正式信号需求另行评审。
- 日均消耗是「系统已经放量」的反馈信号，选出来的是已被验证的素材，不是被低估的素材；若目标是发现未放量素材，应改用不依赖消耗的 D 档。
- 标签是现有投放下的未来 ROI，不等于新建放量任务的增量 ROI。
- 存在幸存者偏差；单窗口数据未验证时间漂移。
