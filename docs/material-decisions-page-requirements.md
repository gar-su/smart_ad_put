# 素材维度决策日志需求（原型预览）
> 本文已被 `docs/decision-signals-requirements.md` 取代，仅保留作历史记录。
## 一、背景
素材选品目前处于策略验证与原型展示阶段：已完成生命周期规则、A 方案三道选品闸门和离线回测。
本期不定义正式的素材投放信号，只先做前端原型展示。
现有决策日志页只展示短剧 / 广告单元信号，且没有目标维度筛选；素材信号即使产出，也无法单独查看。
---
## 二、目标与非目标
**目标**：
- 决策日志页支持「目标维度」筛选：全部 / 短剧 / 广告单元 / 素材
- 目标维度筛选与现有「信号类型」筛选可组合
- 维度列支持「素材」标签
- 用 4 条素材 mock 信号预览素材级 `FOLLOW_UP` 的展示
**非目标**：
- 不实际产出素材信号，不接后端
- 不新增页面或导航
- 不展示累计 ROI / ROI 波动率 / 日均消耗等闸门指标
- 不做阈值编辑、不做筛选持久化
---
## 三、素材信号口径
素材信号沿用 `BuildSignal` 契约：

| 字段 | 素材取值 |
|---|---|
| signal_type | `FOLLOW_UP` |
| target_dimension | `material` |
| target_id | 素材 filename |
| language_code | 素材语言 |
| script_no | 剧本编号 |
| shortplay_name | 所属短剧名 |
| reason | 选品通过原因，文本内可带闸门数值 |
| confidence | 生命周期阶段判定置信度 |
| timestamp | 信号生成时间 |

未来接入时的触发口径（本期不实现）：
- 阶段为 `material_entry` 或 `material_sustained`
- 且通过 A 方案三道闸门：累计 ROI > 50%、ROI 波动率 <= 0.50、日均消耗 >= 200
---

## 五、mock 数据要求
新增 4 条素材信号，覆盖不同语言和短剧：

| 字段 | 要求 |
|---|---|
| target_id | 使用真实素材命名风格，如 `007_Shuer_QT_EN_LA274_260608_FF_MYAISC` |
| language_code | 英语 / 韩语 / 阿拉伯语 / 西班牙语等 |
| shortplay_name | 使用短剧名，如 `Road of Lust` |
| reason | 形如 `选品通过: 累计ROI=68.4% > 50%，波动率=0.23 ≤ 0.50，日均消耗=412.0 ≥ 200` |
| confidence | 0.80（入场期）或 0.85（稳定期） |
| timestamp | 2026-09-07 当天，便于和现有 mock 混排 |
---
## 六、验收标准
| 项 | 标准 |
|---|---|
| 默认列表 | 展示全部维度信号 |
| 维度筛选 | 选「素材」后只展示 4 条素材信号 |
| 组合筛选 | 素材 + 跟投 = 4 条；素材 + 淘汰 = 空态 |
| 维度标签 | 素材行显示「素材」标签 |
| 翻页重置 | 切换任一筛选后回到第 1 页 |
| 详情 | 素材行详情 JSON 含 `"target_dimension": "material"` |
| 预览提示 | 页面可见「素材信号为预览」 |
| 回归 | 短剧 / 广告单元筛选结果与改动前一致 |
